# Drop this week's spreadsheets here

Each week, put the two files in this folder and press **Refresh** (or `F5`) in
the app:

- `stats.xls` — the standings export
- `ACQL Dashboard.xlsx` — the workbook

Filenames do not matter. Each file is identified by what is inside it, so a
re-download saved as `stats (2).xls` is recognised correctly and a byte-for-byte
duplicate is ignored rather than counted twice.

Old exports are worth keeping. Every weekly `stats.xls` states its own week, so
leaving previous weeks in place lets the app rebuild the full season history.
