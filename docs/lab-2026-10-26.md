# Operation Sunday Lab (2026-10-26)

A private research site for the ten upgrades in the brief, run on this computer only:

    python -m acql.lab            # then open http://127.0.0.1:8765
    python -m acql.lab --offline  # no ESPN polling

Why a separate site rather than the public ACQL page: Deadeye's forecasts stay off the public website (standing
rule), the project folder auto-publishes that website, and the assistant needs a server to keep the API key
private. Nothing in the public site (`acql/ui/pool_page`) was changed.

| Feature | Where | Data behind it |
|---|---|---|
| 1 Animated game states | `page.html` LIVE (`drawCard`) | ESPN scoreboard via `live.py` |
| 2 Team pages (32) | `page.html` teams / `data.teams` | stored scores + lines, forecast log, ratings, nflverse |
| 3 Strength over time | `page.html` strength / `data.strength` | `model/teamstrength` (own) + `pool/survivor.ratings` (market) |
| 4 Calibration | `data.calibration` | forecast log, eligible forecasts only |
| 5 Confidence distribution | `data.distribution` | forecast log + eligible moneyline forecasts |
| 6 Sportsbook prices | `data.books` | raw Odds API answers already archived in %LOCALAPPDATA%\ACQL\raw |
| 7 Stats explorer | `data.stats` | nflverse `stats_team_week_YYYY` + `games.csv` |
| 8 Live updates | `live.py`, `/events` (SSE) | one shared ESPN poller, back-off, last good snapshot |
| 9 Postmortems | `data.postmortems`, `research_summary` | forecast log, stored line history, nflverse starting QBs |
| 10 Assistant | `assistant.py`, `/api/ask`, `/api/tool` | Claude (`claude-opus-5-5`) with 8 read-only tools |

Tests: `python tests/test_lab.py` (20 tests, scratch data, no network, no API spend).

## Gaps (data, not code)

- Calibration rests on 14 eligible Deadeye forecasts (week 6); the other 48 were recorded after kickoff and are never scored.
- nflverse team stats stop at 2026 week 5 (file from 2026-10-12); refreshing it is a download that needs Sam's OK.
- Third-down, red-zone, success rate and player stats need nflverse play-by-play / player files (not downloaded).
- No 2026 injury reports and no weather kept per forecast, so postmortems say so instead of showing them.
- Sportsbook prices are whatever the US-region Odds API answers held (9 books); no new fetches are made.
- The assistant has not been asked a real question (that spends API credit); its loop is tested with a fake client.
